# 实验室安全官 · 异常实验夜

一款把实验室安全判断融入装备成长的俯视像素生存游戏。玩家穿越物理、化学、生物三座实验室，移动躲避、自动攻击、收集研究点，并通过安全知识答题强化装备。

开发者：**聆风语**。玩法灵感参考 **Brotato**，像素美术方向参考 **Stardew Valley**。项目采用 [MIT 许可证](LICENSE)。

- **在线试玩**：[异常实验夜](https://lingfengyuthu.github.io/lab-safety-officer/)
- **GitHub 仓库**：[LingFengyuTHU/lab-safety-officer](https://github.com/LingFengyuTHU/lab-safety-officer)

## 当前内容

- **3 座实验室、12 波挑战**：按物理、化学、生物顺序推进，各区有不同的配色、家具、敌人与桌台布局。
- **8 种器材武器、16 种模块**：最多同时装备 6 把武器，武器可升至 IV 级；每把同时使用一个模块，更换时替代原模块。
- **12 类普通敌人与 3 种大型敌人**：结合追击、冲锋、远程攻击、分裂和召唤等行为。
- **72 道安全题**：用电 12、通用 14、消防 14、化学 16、生物 16；附答案、解析与公开资料出处。
- **题库与复习**：分类浏览、关键词搜索、随机练习、错题复习。
- **原创八比特音乐《微光值夜》**，可分别控制音乐、音效与音量；提供轻松难度和休整存档。

## 运行与操作

打开在线试玩链接即可游玩。离线可使用现代 Chrome 或 Edge 打开 `index.html` 或 `实验室安全官_单文件版.html`，无需安装游戏、启动服务器或联网加载运行资源。

这两个 HTML 是同一内容的分发入口，程序、题库、八张图集和音乐音符已内嵌。音乐由浏览器实时合成，首次点击开始或设置后才播放；旁边的 WAV 不参与游戏运行。题目来源链接需要联网访问。

| 操作 | 作用 |
| --- | --- |
| WASD 或方向键 | 移动，武器自动瞄准与攻击 |
| ESC | 暂停或继续 |
| 靠近掉落光球 | 收集研究点，用于休整强化 |
| 首页题库 | 分类查题、看解析、练习及复习错题 |
| 设置 | 音乐、音效、音量和新局难度 |

推荐电脑键盘与较宽窗口。游戏实现了触摸拖动，但未全面验证所有移动设备。资源已自包含；演示前请在实际使用的浏览器确认本地文件打开、声音启动及存储行为。

## 一局怎样推进

1. 选择移液枪或灭火器作为起始武器，回答每波的“出发检查”。答对获得本波指定属性 10% 加成，答错受到 5% 减益；效果只持续当前波。
2. 战斗中移动避敌、利用桌台、拾取研究点。前十一波以生存到时为主，第 4、8 波的大型敌人可选击杀。
3. 休整时从四张随机候选中选择强化。每站最多尝试两次，可免费刷新候选一次。**答对才扣研究点并获得强化；答错不扣点，但消耗一次强化机会。**
4. 地图在第 5、9 波切换，怪物压力和强化价格逐步增长。实验室顺序固定，各区桌台布局有随机变化。
5. 第 12 波必须在 90 秒内击败最终首领培养基巨蕈。胜负结算后可复习本局错题。

若十二波计时全部跑满，战斗时间合计 10 分 15 秒，另加答题、休整和暂停时间；提前击败最终首领会缩短时长。

设置、错题和休整进度保存在本机浏览器。**开始战斗后会清除该休整存档，战斗中关闭页面不能续接本局。** 不同浏览器、设备、本地文件与线上站点之间不共享记录；浏览器限制存储时可能无法保存。项目没有账号、云存档、成绩后台或在线排行榜。

GitHub 仓库根目录是游戏源码项目：

```text

README.md                          本说明

.nojekyll                          静态发布标记
src/                               可编辑源码与构建脚本
assets/art/                        八张最终像素图集
assets/audio/                      原创音乐 WAV 与乐谱资料
docs/                              题库出处与素材生成记录
```

如果拿到的是“最终作品”交接压缩包，目录有所不同：源码项目位于 `最终作品源文件/`，可直接运行的中文 HTML 放在外层，另附 `ppt及讲稿/`、`宣传视频/`、AI 接手文档和组员手册。**这些展示和交接材料不属于当前 GitHub 仓库内容。** 当前交接包的中文 HTML 与内部 `index.html` 内容一致。

源码、题库、图集和构建工具足以继续开发游戏，不依赖原开发目录。音乐资料和图集保留供维护使用，HTML 运行时不读取外置资源。交接包不包含全部历史开发快照和视频剪辑工程。

## 继续开发

使用 Node.js 18 或以上版本，在仓库根目录（交接包中为 `最终作品源文件/`）运行：

```sh
npm run build
```

也可以执行 `node src/build.mjs`。没有第三方依赖，无需先执行 `npm install`。构建会读取 `src/` 和 `assets/art/`，覆盖**当前项目目录内**的 `index.html` 与 `实验室安全官_单文件版.html`；两份输出一致。

请修改源文件后重新构建，不要直接维护生成的 HTML。若在交接包内构建，外层旧的中文 HTML **不会自动更新**，确认新产物后需另行同步。建议先在副本开发，再替换正式分发文件。

| 源文件 | 作用 |
| --- | --- |
| `src/index.template.html` | 页面骨架和资源嵌入位置 |
| `src/style.css` | 首页、设置、题库、题卡与休整界面样式 |
| `src/world.js` | 武器、敌人、地图、布局与波次时长配置 |
| `src/core.js` | 战斗模拟、碰撞、掉落、商店和升级规则 |
| `src/app.js` | 绘制、输入、页面流程、答题和本地存储 |
| `src/questions.js` | 72 道题、答案、解析和来源 |
| `src/audio.js` | 八比特音乐、音效与浏览器合成逻辑 |
| `src/build.mjs` | 把代码、题库和八张图集嵌入单文件 HTML |

### 修改题库

编辑 `src/questions.js` 的 `window.LAB_QUESTIONS`。每道题包含唯一 `id`、分类 `tag`、题干 `q`、三个 `options`、正确选项下标 `answer`、解析 `why`、`sourceTitle` 和 `sourceUrl`。

`answer` 从 **0** 开始。分类使用 `electric`、`general`、`fire`、`chemical`、`bio`。增加或修改题目时核对答案与出处，保留适用场景；更新后重新构建，已生成的 HTML 才会包含改动。

来源说明见 `docs/03_试作题库来源.md` 和 `docs/04_完整题库来源.md`：前者记录首批题目，后者记录扩充内容，两份都属于当前完整题库。资料包括公开标准、检查表及高校规程，题目为项目整理改写，并非专家认证题库。真实实验应遵循所在单位的现行规程与专业指导。

### 修改图集与音乐

图集在 `assets/art/`。替换时保持网格行列、帧顺序、透明边距与角色锚点；尺寸或布局变化时同步调整 `src/app.js` 的取图逻辑。新增图集还需改 `src/build.mjs` 的资源映射。`docs/` 中的两份素材 JSON 保留生成提示词；其中历史路径只用于追溯，不参与运行。

实际游戏音乐在 `src/audio.js` 中通过 Web Audio 合成；`assets/audio/` 的 WAV 为独立试听版，JSON 为归档乐谱。仅替换 WAV 或 JSON 不会改变游戏内音乐。

## GitHub Pages 发布

本项目已部署，当前发布来源为 **main 分支根目录**。更新游戏时，将源码、素材及重新构建的 HTML 一起提交到发布分支；部署现成 HTML 不需要在线安装 Node.js 或执行构建。

自行部署副本时，将源码项目的内容放在仓库根目录，让 `index.html` 直接位于根目录。在仓库 Settings → Pages 选择 Deploy from a branch，指定发布分支与 `/(root)`。具体步骤参见 [GitHub Pages 发布来源说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

请不要把整个“最终作品”交接外层直接上传为站点根目录，否则入口会多嵌套一层。修改后的副本应同步自己的网址和二维码，避免仍然指向原项目。

## 创作与用途

像素图集由本项目借助 AI 图像工具生成并整合，没有使用参考游戏的原始素材；《微光值夜》使用原创乐谱和合成音色，无外部音乐采样。代码与展示材料制作也有 AI 辅助。Brotato 和 Stardew Valley 仅为玩法、美术方向参考，不代表关联或官方合作。

器材武器和异常怪物属于虚构游戏表现，不能作为现实实验操作示范。作品定位为实验室安全宣传与复习入口，可以用于安全周、迎新或路演互动；目前未开展教学效果量化研究，不替代正式培训与准入考核。
