# 实验室安全官

清华大学第七届平安校园——实验室安全知识大赛参赛作品（A 赛道 · 小游戏形式）。

一个关于实验室安全隐患排查的浏览器小游戏。玩家把放错位置的试剂、废弃物、气瓶和操作归到正确的地方，每归位一次，解锁一条规范依据与正确做法。

## 在线试玩

部署到 GitHub Pages 后，地址为：

```
https://lingfengyuthu.github.io/lab-safety-officer/
```

## 本地运行

直接双击 `01_可执行文件/实验室安全官.html` 即可，无需安装任何环境，断网也能玩。

## 修改题目

改 `02_源代码/src/data/knowledge.js` 一个文件就够了。结构很简单：`KNOWLEDGE` 存知识点，`LEVELS` 存关卡（容器 slots、项目 items、危险组合 traps）。

改完重新打包：

```bash
python build/build_single.py
```

## 自检

```bash
node build/verify.js
```

会检查数据完整性（项目与容器的对应、知识点是否存在）以及单文件是否真的不依赖外部文件。

## 知识点来源

主要参考 GB 15603-2022《危险化学品仓库储存通则》、GB/T 7144-2016《气瓶颜色标志》、GB 18597、HJ 2025、GB 55037-2022、GB 50016，以及生态环境部与各地发布的实验室危险废物环境管理指南、实验室危险废物污染防治技术规范。

完整清单见 `05_说明文档/知识点与规范依据清单.md`。

## 一处特别说明

废液桶的颜色标识全国没有统一标准，北京、湖南、江苏和部分高校的规定互不相同。因此游戏不以颜色作为判定标准，改用化学性质分类；颜色只作识别提示，并注明以所在单位规定为准。
