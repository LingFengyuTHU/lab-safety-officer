# 实验室安全官

清华大学第七届平安校园——实验室安全知识大赛参赛作品（小游戏赛道）。

一款关于实验室安全隐患排查的浏览器游戏。玩家扮演实验室安全官，在六个场景中完成**归位排查、配伍禁忌实验、情境决策**三段任务，判断哪些物品放错了位置、哪两样试剂不能放在一起、突发情况该怎么处置。

**65 条安全知识点，每条标注可核查的规范依据。**

## 运行

双击 `01_可执行文件/实验室安全官.html` 即可。无需安装、无需联网、不加载任何外部资源。

也可双击 `01_可执行文件/实验室安全官.exe`（Windows 自解压包，会先解压到临时目录再打开浏览器）。

技术栈：原生 HTML、CSS、JavaScript，零第三方依赖，单文件 845 KB。桌面与移动端均适配。

## 玩法

每关三个环节：

| 环节 | 做什么 | 判定方式 |
| --- | --- | --- |
| 归位排查 | 把放错位置的试剂、废弃物、气瓶拖回正确容器 | 拖拽或点选，落位即判定 |
| 配伍禁忌实验 | 给出两种试剂，先预测反应，再看实际结果 | 三选一预测，与实际结果比对 |
| 情境决策 | 面对一个真实事故场景，选择第一时间的正确动作 | 四选一，附逐项解析 |

错误不直接扣分，而是累积**隐患值**。归位错误 +1，触发禁忌组合 +3，情境决策错误 +2。隐患值满 5 格本关重来。这样错误有实际代价，但不会让玩家一次失手就退出。

结算页按掌握程度分层回顾，游戏中的知识手册实时标记已掌握的条目。

## 关卡

| 关卡 | 主题 | 归位项目 | 配伍实验 | 结果 |
| --- | --- | --- | --- | --- |
| 第 1 关 | 化学品储存柜 | 12 | 次氯酸钠溶液 + 浓盐酸 | 剧烈反应 |
| 第 2 关 | 废弃物分类 | 10 | 二氯甲烷废液 + 乙醇废液 | 视条件而定 |
| 第 3 关 | 配伍禁忌实验 | 13 | 过氧化氢 30% + 丙酮 | 剧烈反应 |
| 第 4 关 | 用电与消防 | 8 | 金属钠 + 消防水 | 剧烈反应 |
| 第 5 关 | 高压高温与气瓶 | 10 | 氧气瓶 + 乙炔瓶 | 剧烈反应 |
| 第 6 关 | 应急处置 | 10 | 稀盐酸废液 + 氢氧化钠废液 | 平稳共存 |

第 2 关与第 6 关的实验结果为「视条件而定」与「平稳共存」，用于说明并非所有组合都会立刻剧烈反应——判断依据是反应物性质与条件，不是背结论。

## 修改内容

只需改 `02_源代码/src/data/knowledge.js` 一个文件。该文件是运行时唯一数据源，包含四个常量：

| 常量 | 内容 |
| --- | --- |
| `KNOWLEDGE` | 65 条知识点，含标题、类型、说明、方程式、规范依据、正确做法 |
| `LEVELS` | 6 个关卡，含容器、项目、禁忌组合 |
| `SCENARIOS` | 6 道情境题，含四个选项与逐项解析 |
| `REACTIONS` | 6 组配伍实验，含现象描述与原理说明 |

改完执行：

```bash
node build/verify.js              # 10 项数据与文件自检
node build/audit_basis.js         # 依据可核查性审计
python build/build_single.py      # 重新打包单文件
python build/make_exe.py          # 重新生成 exe
```

`build/gen_basis_doc.js` 与 `build/gen_levels_json.js` 分别由数据源生成依据清单与关卡配置，因此两份文档与游戏内容始终一致。

## 规范依据

全部 128 条依据分两类：101 条给出标准编号与年号，27 条给出法律、行政法规或部门规章的全称与发布文号。无一条使用「有关规定」这类无法核查的表述。

核查中修正过的两处问题：

- GB 13690-2009《化学品分类和危险性公示 通则》已于 2025-08-01 废止，改引 GB 30000.1-2024《化学品分类和标签规范 第1部分：通则》
- GB/T 13869-2017 的标准名称为《用电安全导则》，并非实验室废物管理文件，实验室废弃化学品的收集贮存改引GB/T 31190-2014 与 GB 18597-2023

逐条清单见 `05_说明文档/知识点与规范依据清单.md`，可直接作为核查材料使用。

## 一处特别说明

废液容器的颜色标识全国没有统一标准，北京、湖南、江苏与部分高校的规定互不相同。因此游戏不以颜色作为判定依据，改用化学性质分类；颜色仅作识别提示，并注明以所在单位规定为准。气瓶颜色则依据 GB/T 7144-2016，判定时同时核验瓶色、字样与检验色标，不单看颜色。
