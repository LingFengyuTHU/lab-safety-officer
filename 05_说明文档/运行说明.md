# 运行说明

## 方式一：双击 HTML（最推荐）

打开 `01_可执行文件/实验室安全官.html`。

双击即可，不需要安装任何东西，不需要联网。Chrome、Edge、Firefox、360 浏览器、Safari 的近两年版本都能正常打开。手机浏览器也可以，操作支持触屏拖拽。

这个文件是自包含的：样式、脚本、七张插画全部打包在里面，所以不会出现"图片丢失"或者"路径错误"这类问题。整个文件 415 KB。

## 方式二：双击 exe

打开 `01_可执行文件/实验室安全官.exe`。

这是把上面那个 HTML 封装成的 Windows 可执行文件，双击后会解压并自动用系统默认浏览器打开游戏。因为要经过解压这一步，首次打开会比方式一慢一到两秒，属正常现象。

需要说明的是，这个 exe 本质上是一个自解压包，不是原生程序，所以部分杀毒软件可能会提示"未知发布者"。这是自解压文件的常见情况，不影响使用。如果介意，直接用方式一。

## 方式三：命令行启动本地服务

如果需要在服务器上跑，或者想在多个设备上访问，可以把 `docs/` 目录作为静态站点根目录：

```bash
python -m http.server 8000 --directory docs
```

然后浏览器访问 `http://localhost:8000`。

不需要后端、不需要数据库，纯静态。

## 常见问题

**打开后是空白页？**

检查浏览器版本。游戏用了一些较新的 CSS 特性，如果浏览器是 2020 年之前的版本，可能会出现布局异常。换用较新版本的 Chrome 或 Edge 即可。

**拖拽没反应？**

可以改用点击方式：先点一下左边的项目，再点一下右边的容器。触屏设备推荐用这种方式。

**想改题目怎么办？**

用文本编辑器打开 `02_源代码/src/data/knowledge.js`，文件里的结构很好认：

- `KNOWLEDGE` 是知识点字典，每条包含标题、说明、规范依据、正确做法
- `LEVELS` 是关卡数组，每关包含 `slots`（容器）、`items`（项目）、`traps`（危险组合）

改完运行下面的命令重新打包成单文件：

```bash
python build/build_single.py
```

想验证改动有没有写错：

```bash
node build/verify.js
```

这个自检脚本会检查项目与容器的对应关系是否完整、知识点是否都存在、单文件是否真的不依赖外部文件。
