## 二、重要：两个大缓存（建议清理，但需你确认）

清理这两个能腾出约 4 GB，都是**可再生的缓存**，删除不影响任何已安装的软件。

### 1. pip 缓存 — 2.7 GB

```
C:\Users\lenovo\AppData\Local\pip\cache
```

这是 pip 下载安装包时的缓存。删了以后下次装包会重新下载，没有其他影响。

清理命令：
```bash
python -m pip cache purge
```
或直接删除该目录。

### 2. Playwright 浏览器 — 1.4 GB

```
C:\Users\lenovo\AppData\Local\ms-playwright
```

里面有 6 个目录：chromium-1228、chromium-1234、chromium_headless_shell-1228、chromium_headless_shell-1234、ffmpeg-1011、winldd-1007。

其中 **`chromium-1228`、`chromium_headless_shell-1228`、`ffmpeg-1011`、`winldd-1007` 是旧版本残留**，可以删。保留 1234 这两个即可（如果以后还要用 playwright）。

如果你的电脑上没有其他项目在用 Playwright，整个目录删掉也没问题。

> 注意：这几个目录名看起来相似但版本号不同，删除时请认准 **1228** 和 **1234** 的区别。建议先只删 1228 那两个。
